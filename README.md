# AZ-104 Microsoft Azure Administrator Notes and Labs

This repository contains my AZ-104 course notes, hands-on lab write-ups, screenshots, and revision tracking for the Microsoft Azure Administrator certification.

The notes are written as an Obsidian vault, so the best way to read them locally is to open this folder in Obsidian. Markdown files can also be browsed directly on GitHub.

## What is Included

- Module notes for all 11 AZ-104 course areas
- 14 hands-on lab write-ups
- Architecture and portal screenshots from the labs
- An exam objectives tracker mapped to the official AZ-104 skills measured
- Recall checks for revision
- A publishing workflow and LinkedIn post draft

## Repo Notes

This repo is for learning evidence and revision. It contains notes and lab screenshots, not production Azure credentials or reusable infrastructure for a live environment.

Before publishing, check that screenshots do not expose subscription IDs, tenant IDs, email addresses, IP addresses, access keys, tokens, or other private details.
